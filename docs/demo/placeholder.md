# 占位符插值预览

> 国际化文案里常用 `{name}`、`{count}` 这类占位符。这个小工具可以实时预览插值结果，帮你在写语言包时快速核对。

<PlaceholderPreview />

## 用法

1. 在「消息模板」输入框输入带占位符的文案，例如：
   ```
   你好，{name}！你有 {count} 条新消息。
   ```
2. 在「参数」输入框输入一个 JSON 对象，例如：
   ```json
   { "name": "小明", "count": 3 }
   ```
3. 下方实时显示预览结果：
   ```
   你好，小明！你有 3 条新消息。
   ```

## 说明

- 占位符语法：`{任意字母或数字下划线}`
- 参数必须是合法 JSON 对象
- 模板里缺失的 key 会原样保留，方便你发现遗漏

> 这个工具对应的 `vue-i18n` 插值原理见 [Vue i18n 快速上手](/vue-i18n/start) 第 7 节。
